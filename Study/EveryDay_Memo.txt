    import java.util.Arrays; 에서 int[] arr = Arrays.copyOf(원래_리스트, 신규 리스트의 길이) 를 하면 기존 배열의 길이를 조절 가능
    삼항 연산자 ? -> 조건문 한번을 줄여줌. ex) a = a < b ? 1 : 0; 하면 a가 b보다 작다면 1, 크다면 0을 a에 대입함.
    계속 실수하는 것 : char or string을 다룰때 '' "" 생략하지 말 것. 연산자 = 과 == 구별해서 쓰기. 
    for(char ch : str.toCharArray()) : 문자열을 char[] 배열로 쪼개서 ch에 하나씩 담아서 반복
    switch 문 : 위에 for-each와 결합해 switch(ch) { case Alpha : n++; break; ... }으로 케이스를 정할 수 있다.
4일차 : 프로그래머스 문제를 여러개 풀어본다. 이 과정 속에서 AI에게 물어보고, 새로운 점을 알아가자. 
    import java.util.ArrayList; 에 대하여...
    ArrayList : ArrayList<Integer /* 또는 Double, Character*/> list/*리스트 이름*/ = new ArrayList<>(); 로 선언한다.
    list.add(추가할 데이터) -> 값 추가, int i = list.get(idx번호); -> 특정인덱스 추출
    int length = list.size(); -> 길이 확인, list.isEmpty() -> 리스트가 비어있는지 확인. list.remove(0) -> 0번방 삭제
    주의사항 : stream을 배우기 전까지는 마지막에 다른 배열에 for문을 이용해 ArrayList에 저장된 값을 넣어줘야 함.

    Integer.toBinaryString(k); -> k에 있는 수를 이진수로 바꾸는 것.
    trim()과 split() -> trim은 앞뒤 공백 제거, split은 해당 문자를 기준으로 array를 나눔.
    split("\\s+")을 하면 공백(\\s)이 몇 개든 상관없이 한 개로 취급하고 split을 진행.
    Arrays.copyOfRange(list, 시작점, 끝점) -> list의 특정 범위를 가져오는 명령
    Arrays.sort(list) 배열을 오름차순으로 정리.
    string.contains(target) -> string 안에 target이 있나 검사
    string.substring(i,j) -> i부터 j까지 string 추출, (i)만 하면 i부터 끝까지
